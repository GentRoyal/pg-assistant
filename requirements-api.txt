# Runtime dependencies for the deployed API only.
#
# OCR (rapidocr, onnxruntime, opencv) and torch/transformers are deliberately
# absent: scanned PDFs are ingested from a developer machine, and keeping those
# out is what makes the API fit a small instance. The server does process text
# PDFs that admins upload, which needs only pymupdf.
#
# This works only with EMBEDDING_PROVIDER=openai or gemini. With
# EMBEDDING_PROVIDER=local the server needs torch + transformers, so deploy
# requirements.txt instead and give it at least 1 GB of memory.

fastapi
uvicorn
supabase
python-dotenv
openai
tiktoken

# Admin uploads: form parsing, and reading text PDFs on the server (no OCR)
